This document illustrates the functioning of the Expectation-Maximization (EM) algorithm on arguably its simplest instance: a two-component univariate Gaussian mixture model. It accompanies Chapter 2 (“Latent variable models and the EM algorithm”) of the book.

1. Palmer penguins dataset

As a first illustrative example, let us consider the Palmer penguins dataset . The dataset contains the measurement of bill length for \(342\) penguins collected from three islands in the Palmer Archipelago, Antarctica.

ggplot(penguins %>% na.omit(),aes(x=bill_length_mm)) +
  geom_histogram(color = "black",fill="cyan4", breaks = seq(32, 60, by = 1)) +
  labs(x = "Bill length (mm)", y = "Counts") +
  scale_x_continuous(breaks = seq(35, 55, by = 10))

Our objective is to model the distribution of bill length in Palmer penguins.
A quick look at the histogram of bill length suggests that a simple Gaussian distribution is not adequate. Indeed, the distribution exhibits multiple local modes (peaks), indicating that it may not originate from a single homogeneous population. Since the distribution of a trait within a homogeneous population is typically assumed to follow a Gaussian distribution, this observed multimodality may reflect the presence of heterogeneous subpopulations, each with distinct bill length characteristics.

Note

Note that the dataset actually includes information on both species and sex. However, for the purpose of this introductory example, we intentionally ignore these variables.

Mixture of two gaussian distributions.

The feature of the data naturally motivates the use of a (Gaussian) mixture model. Let \(\{y_i\}_{1 \leq i \leq n}\) denote the \(n\) observed bill lengths.
We assume these are realizations of \(n\) independent random variables \(\{Y_i\}_{1 \leq i \leq n}\) that follow a two-component Gaussian mixture distribution.

ImportantMixture of two Gaussians

We introduce, for each observation \(i\), a latent (unobserved) variable \(Z_i \in \{1,2\}\) indicating which component generated \(y_i\). Conditionally on \(Z_i = k\),

\[ y_i \mid Z_i = k \ \sim\ \mathcal N(\mu_k,\sigma_k^2), \qquad P(Z_i = 1) = p . \]

EM maximises the (non-concave) likelihood function iteratively: EM is widely described in Chapter 2 of the book, with all the necessary technical details for its application on the mixture of two gaussian distributions. Please refer to this book if needed. The helper functions implementing the E step, the M step and the log-likelihood are provided in Functions_EM.R.

source("Functions_EM.R")

Simulating data

To further investigate the behavior of the EM algorithm, we consider a special case where the parameters \((p,\sigma^2_{1}, \sigma^2_2)\) are known and fixed to their true values, and only \((\mu_1, \mu_2)\) are to be estimated. For this experiment, we simulate data using the parameters \(p = 0.3\), \(\sigma^2_1= \sigma^2_2=1\), and \((\mu_1,\mu_2)=(2, 5)\).

Data simulation 
p.true <- 0.3
mu.true <- c(2, 5)
sd.true <- c(1, 1)
n <- 500

res_EM_only_mu <- file.exists("res_EM_toy_mixture.Rdata")

if (res_EM_only_mu) {
    # Load cached results -> y , res_like_surface, res_all_run_only_mu 
  load("res_EM_toy_mixture.Rdata")
}else{
  set.seed(3852)
  # Latent component membership
  Z <- rbinom(n, 1, p.true)          # Z_i = 1 with prob p
  y <- ifelse(Z == 1,rnorm(n, mu.true[1], sd.true[1]),
            rnorm(n, mu.true[2], sd.true[2]))
  df_y <- data.frame(y = y)
}

The shape of the objective function

The observed-data log-likelihood of a mixture is multi-modal. To visualise it, we fix \(p = 0.3\) and the variances \(\sigma_1^2=\sigma_2^2=1\) at their true values, and evaluate \((\mu_1,\mu_2) \mapsto \ell(y_1, \dots, y_n;\theta)\) on a grid:

Compute the surface 
if (!res_EM_only_mu) {
  N <- 150
  grid_mu1 <- seq(0, 7, length.out = N)
  grid_mu2 <- seq(0, 7, length.out = N)

  res_like_surface <- expand.grid(mu1 = grid_mu1, mu2 = grid_mu2)
  res_like_surface$loglik <- vapply(seq_len(nrow(res_like_surface)), function(i) {
    pars <- list(mu = c(res_like_surface$mu1[i], res_like_surface$mu2[i]),
                 var = sd.true^2, p = p.true)
    logLikelihood(pars, y)
  }, numeric(1))
}

Because the component weights are fixed to \(p = 0.3\) (and not \(0.5\)), the surface is not symmetric under the exchange of \(\mu_1\) and \(\mu_2\). Its global maximum lies at \((\mu_1,\mu_2) \approx (2,5)\).
In the surface plot, you can observe local maxima and saddle points. The difficulty for EM comes from the fact that the algorithm can be trapped away from the global maximum, as illustrated below.

Pplot the surface

EM behavior on the likelihood surface

We run EM — updating \(\mu_1\) and \(\mu_2\) only (variances and weight fixed, so that the trajectories stay in the \((\mu_1,\mu_2)\) plane of the surface above) — from several starting points:

Run the EM from various starting points 
theta0_mu <- list(
  list(mu = c(1, 2),   var = c(1, 1), p = 0.3),
  list(mu = c(0.5, 4), var = c(1, 1), p = 0.3),
  list(mu = c(6, 1),   var = c(1, 1), p = 0.3),
  list(mu = c(5, 6.5), var = c(1, 1), p = 0.3),
  list(mu = c(6, 6),   var = c(1, 1), p = 0.3)
)

if (!res_EM_only_mu) {
  res_all_run_only_mu <- do.call(rbind, lapply(seq_along(theta0_mu), function(run) {
    res <- EM_2Mixture(theta0_mu[[run]], y, tol = 1e-5,estim_only_mu = TRUE)
    
    cbind(res,
          Init    = run,
          numIter = seq_len(nrow(res)))
  }))
  res_all_run_only_mu$Init <- factor(res_all_run_only_mu$Init)
  save(y,res_all_run_only_mu, res_like_surface, file="res_EM_toy_mixture.Rdata")
}
Plot the trajectories 
gg_surface  + geom_point(aes(x = mu.true[1], y = mu.true[2]),
             shape = 0, colour = "red", size = 4) + 
  geom_line(data = res_all_run_only_mu, aes(colour = Init), linewidth = 1) +

The crosses mark the starting points and the red square the true parameter \((\mu_1,\mu_2) = (2,5)\); each colored line is the path of the EM updates. Three distinct convergence points can be observed: one corresponds to the global maximum of the likelihood (marked by the green point), which is close to the true parameter values (red square); another corresponds to a local maximum (bottom right); and the third corresponds to a saddle point of the likelihood surface (center of the figure).

This toy example illustrates the practical importance of initializing the EM algorithm from multiple or carefully chosen starting points, in order to explore different regions of the parameter space and improve the chances of reaching the global maximum.
